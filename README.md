# Joshua Yorko’s portfolio and résumé

Build the static site with Node.js 22 or newer.

```sh
node portfolio/build.mjs
```

The build writes `portfolio/dist/`. It uses the catalog snapshot and approved résumé in this checkout. [Local browsing, checks, and experiment provenance](portfolio/README.md).
