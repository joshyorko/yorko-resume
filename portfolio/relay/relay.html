    Model, simulation and license

    The repair agent ranks three allowed changes with a synthetic Naive Bayes model running on CPU in WebAssembly. Its scores are relative log scores. The verifier reruns the incident and four independent delivery checks before accepting the change.

    Training uses 18 authored incident notes. The runtime embeds {{kernelBytes}} bytes of WebAssembly and {{weightBytes}} bytes of learned weights. All parcels and tools are simulated in memory. No network, account or browser storage is needed.
